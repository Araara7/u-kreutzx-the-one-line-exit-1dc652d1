One funny single-line resignation letter, written by a small deterministic
Python program for the [make.fun](https://make.fun) bounty
"The One-Line Exit".

## Entry

> I hereby resign, effective now — I came for the free snacks, stayed for the trauma, and today the snacks ran out.

## Run

```sh
python3 main.py
```

The program writes the 113-character line to `/output/entry.txt`.
